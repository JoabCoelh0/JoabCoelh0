**Sistema de gestão terapêutica — Projeto de Extensão**

Projeto desenvolvido a partir de uma necessidade real de uma clínica, com o objetivo de estruturar uma solução para auxiliar na gestão de pacientes e processos terapêuticos.

### 🔎 Atividades realizadas

- **Conduzi entrevistas com stakeholders** para levantamento de requisitos.
- **Analisei e documentei requisitos** funcionais e não funcionais.
- **Modelei a solução** de acordo com as necessidades identificadas.
- **Estruturei a documentação técnica** do projeto.
- Apliquei conceitos de **Engenharia de Software e Engenharia de Requisitos** durante o desenvolvimento da solução.

- Consumo de API REST
